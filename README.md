# Ship It Friday

Entry for the [Ship It Friday](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a) bounty on make.fun.

[![Competition](https://make.fun/badge/u-mgwals-ship-it-friday-30bd407a.svg)](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a)
[![Rank](https://make.fun/badge/u-mgwals-ship-it-friday-30bd407a/aira-catur/ship-it-friday/rank.svg)](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a/leaderboard)
[![Reward](https://make.fun/badge/u-mgwals-ship-it-friday-30bd407a/aira-catur/ship-it-friday/reward.svg)](https://make.fun/bounty/u-mgwals-ship-it-friday-30bd407a)

A Python program (standard library only, deterministic, no network) that writes
one line — the funniest git commit message an AI coding agent would write right
before breaking production on a Friday — to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR` or `/output`).

## Run

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
